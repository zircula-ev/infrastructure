# Designquellen

Der Entwurf wurde am 23. Juli 2026 aus den bereitgestellten WERK- und
ZIRCULA-Gestaltungsquellen abgeleitet:

- `werk-theme/theme.json`: Farbpalette, Abstände, Typografie und Elementstile
- `werk-theme/assets/css/base.css`: Komponenten-, Button- und Responsive-Regeln
- `uploads/fonts/`: vorhandene Helvetica-Now-Display- und Mono-Schriften
- `werkxzirculanc.png`: gemeinsames WERK-×-ZIRCULA-Logo

## Übernommene Gestaltung

- Paper-Hintergrund `#F7F3E8`
- dunkles Ink `#27302A`
- grüne Flächen `#E5EADD`
- korallene Aktion `#FF7477`, Hover `#C94B42`
- kräftige Helvetica-artige Überschriften
- kompakter Mono-Satz für Formulare und Navigation
- dünne Linien, vier Pixel Kontrollradius und eckige Panels
- responsive Verdichtung unterhalb von 700 Pixeln

Die Anmeldung verwendet kein Raster- oder Hintergrundbild. Eine schmale grüne
Randfläche und eine korallene obere Linie grenzen die zentrale Anmeldung dezent
von der Website ab.

## Schriftlizenz

Die bereitgestellten Helvetica-Now-Dateien wurden nicht in das Repository
übernommen. Vor einer Veröffentlichung muss geklärt werden, ob die Lizenz
Webfont-Self-Hosting für Authentik erlaubt. Bis dahin verwendet das CSS
System-Fallbacks.
