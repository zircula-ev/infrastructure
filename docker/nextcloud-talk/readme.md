# Nextcloud Talk High Performance Backend

Dieses Verzeichnis enthält den Docker-Stack für das High Performance Backend (HPB) von Nextcloud Talk.

## Ziel

Bereitstellung eines eigenständigen HPB-Stacks für die bestehende Nextcloud-Testumgebung.

## Komponenten

- Nextcloud Spreed Signaling
- NATS
- Janus Gateway
- (später) coturn
