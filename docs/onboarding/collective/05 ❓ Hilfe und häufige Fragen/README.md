# ❓ Hilfe und häufige Fragen

Viele Probleme lassen sich schnell einordnen. Wenn die kurzen Hinweise hier
nicht helfen, sende eine Mail an `itsupport@zircula.org`.

Du musst ein technisches Problem nicht selbst vollständig verstehen, bevor du
um Hilfe bittest. Eine ehrliche Beschreibung dessen, was du siehst, ist meist
hilfreicher als eine Vermutung über die Ursache.
