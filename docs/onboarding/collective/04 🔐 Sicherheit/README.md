# 🔐 Sicherheit

Sicherheit soll die tägliche Arbeit schützen und nicht unnötig erschweren. Die
wichtigsten Regeln sind einfach:

- Nutze nur dein eigenes Konto.
- Teile keine Passwörter oder Anmeldecodes.
- Bestätige keine unerwartete Anmeldeanfrage.
- Sperre dein Gerät, wenn du es verlässt.
- Melde Verlust oder verdächtige Vorgänge schnell.
