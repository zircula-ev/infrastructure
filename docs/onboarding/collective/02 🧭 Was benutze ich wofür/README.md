# 🧭 Was benutze ich wofür?

Unsere Werkzeuge haben unterschiedliche Aufgaben. Die wichtigste Orientierung:

| Ich möchte … | Dafür nutze ich … |
|---|---|
| eine Datei dauerhaft ablegen | Dateien und Team-Ordner |
| gemeinsam Wissen dokumentieren | Collectives |
| kurz etwas besprechen | Talk |
| einen Termin organisieren | Kalender |
| Aufgaben sichtbar planen | Deck |
| E-Mails lesen und schreiben | Mail |
| Arbeitszeit dokumentieren | Arbeitszeitcheck |
| ein technisches Problem melden | LibreDesk / IT-Support |

Ein Link im Chat ist sinnvoll. Die eigentliche Datei oder dauerhafte Information
sollte aber an ihrem vorgesehenen Ort liegen.
