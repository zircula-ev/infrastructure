# 🛟 LibreDesk und IT-Support

LibreDesk ist unser verbindlicher Kanal für konkrete IT-Supportanfragen.
Reguläre Nutzer:innen benötigen dafür kein LibreDesk-Konto.

Sende eine E-Mail an:

```text
itsupport@zircula.org
```

## Eine hilfreiche Supportanfrage enthält

- eine kurze Beschreibung dessen, was du tun wolltest,
- was stattdessen passiert ist,
- ungefährer Zeitpunkt des Fehlers,
- verwendetes Gerät und Browser oder App,
- wenn sinnvoll einen Screenshot ohne Passwörter oder vertrauliche Inhalte.

Antworte auf die erhaltene Ticketmail, damit deine Rückmeldung demselben Fall
zugeordnet bleibt. Sende niemals Passwörter, MFA-Codes oder App-Passwörter per
Mail oder Ticket.
