# ✉️ Mail

Nextcloud Mail zeigt dein bestehendes Vereins- oder Organisationspostfach in der
Cloud an. Es ersetzt nicht den Mailserver, sondern verbindet sich mit deinem
vorhandenen Postfach.

## Postfach hinzufügen

1. Öffne in Nextcloud die App **Mail**.
2. Wähle **Konto hinzufügen** beziehungsweise die manuelle Einrichtung.
3. Trage deine vollständige E-Mail-Adresse und das Passwort deines Postfachs ein.
4. Verwende bei manueller Abfrage diese Werte:

| Einstellung | Wert |
|---|---|
| IMAP-Server | `mail.manitu.de` |
| IMAP-Port | `993` |
| IMAP-Sicherheit | SSL/TLS |
| SMTP-Server | `mail.manitu.de` |
| SMTP-Port | `465` |
| SMTP-Sicherheit | SSL/TLS |
| Benutzername | vollständige E-Mail-Adresse |

Prüfe danach Absendername und Absenderadresse mit einer Testmail. Das
Postfachpasswort ist nicht dein Authentik-Passwort und gehört nicht in ein
Collective, Ticket oder einen Chat.
