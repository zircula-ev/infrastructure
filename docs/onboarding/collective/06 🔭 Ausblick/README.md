# 🔭 Ausblick

Unsere digitale Arbeitsumgebung wird schrittweise weiterentwickelt. Neue
Werkzeuge werden erst eingeführt, wenn Betrieb, Berechtigungen, Backup und ein
verständlicher Arbeitsablauf geklärt sind.

Vorgesehen oder in Prüfung sind unter anderem:

- **Memories** für eine besser durchsuchbare und übersichtlichere gemeinsame
  Foto- und Mediendarstellung,
- **LibreSign** für geeignete Unterschriften- und Formularabläufe,
- **Vaultwarden** für die gemeinsame, sichere Verwaltung dienstlicher
  Zugangsdaten in einem späteren Rollout,
- möglicherweise **Listmonk** für Newsletter und organisierte Mailverteiler.

Diese Nennung bedeutet noch nicht, dass der jeweilige Dienst bereits allgemein
verfügbar ist. Vor einem Rollout gibt es eine eigene Information und – wenn
nötig – eine kurze Anleitung in diesem Onboarding.

Rückmeldungen aus dem Alltag sind ausdrücklich willkommen. Gute Werkzeuge sollen
Arbeit vereinfachen und keine neue parallele Ablage schaffen.
