# 🚀 Schnellstart

Hier findest du alles, was du für deinen ersten Arbeitstag mit der neuen
Umgebung brauchst.

In der Regel reichen diese Schritte:

1. Einladung öffnen und das eigene Konto einrichten.
2. Unter `https://cloud.zircula.org` anmelden.
3. Falls verlangt, MFA beziehungsweise einen Passkey einrichten.
4. Prüfen, ob die erwarteten Team-Ordner und Kalender sichtbar sind.
5. Bei Bedarf die Nextcloud- und Talk-App installieren.

Für die tägliche Arbeit reicht meist der Webbrowser. Zusätzliche Apps sind
hilfreich, wenn du Dateien automatisch synchronisieren, unterwegs chatten oder
Kalender auf deinem Gerät sehen möchtest.
