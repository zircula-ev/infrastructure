# 📝 Dokument gemeinsam bearbeiten

1. Öffne den passenden Team-Ordner in **Dateien**.
2. Öffne eine vorhandene Office-Datei oder erstelle dort ein neues Dokument.
3. Bearbeite das Dokument direkt im Browser.
4. Nutze Kommentare für konkrete Rückfragen zum Inhalt.
5. Teile im Chat nur den Link zur Datei.

Nextcloud speichert Änderungen und frühere Versionen. Lade deshalb nicht nach
jeder Bearbeitung eine neue Datei mit Namen wie `final_neu_2` hoch.

Wenn mehrere Personen gleichzeitig schreiben, achtet auf die sichtbaren
Markierungen der anderen. Bei größeren inhaltlichen Entscheidungen hilft eine
kurze Absprache in Talk.
