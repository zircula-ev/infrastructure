# 02 – Docker Installation

## Ziel

Installation der Container-Plattform auf dem VPS.

## Durchgeführte Schritte

- Docker CE aus dem offiziellen Docker Repository installiert
- Docker Compose Plugin installiert
- Docker Buildx installiert
- Benutzer `timo` zur Gruppe `docker` hinzugefügt
- Funktion mit `docker run hello-world` erfolgreich getestet

## Installierte Komponenten

- Docker Engine
- Docker CLI
- Docker Compose Plugin
- Docker Buildx
- containerd

## Ergebnis

Docker ist betriebsbereit und kann ohne `sudo` verwendet werden.

Die eigentliche Infrastruktur wird in den nächsten Schritten über Docker Compose aufgebaut.
