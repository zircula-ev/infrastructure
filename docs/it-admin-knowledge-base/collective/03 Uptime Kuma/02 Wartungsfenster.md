# Wartungsfenster

Ein Wartungsfenster verhindert unnötige Ausfallbenachrichtigungen während einer
geplanten Arbeit. Die Monitore bleiben dabei nachvollziehbar als in Wartung
markiert.

## Anlegen

1. Im Hauptmenü **Wartung** öffnen.
2. **Wartung planen** auswählen.
3. Eindeutigen Titel und kurze Begründung eintragen.
4. Nur die tatsächlich betroffenen Monitore auswählen.
5. Beginn, Ende und richtige Zeitzone kontrollieren.
6. Benachrichtigungen für das Fenster wie abgestimmt behandeln.
7. Wartung speichern und ihre Anzeige prüfen.

Für einen einzelnen Termin wird ein einmaliges Fenster verwendet. Wiederkehrende
Wartungen werden nur eingerichtet, wenn der Ablauf wirklich regelmäßig ist.

## Nach der Wartung

- Erreichbarkeit der betroffenen Dienste prüfen.
- Kontrollieren, dass das Fenster beendet ist.
- Unerwartete Reststörungen als Vorfall behandeln.
- Ergebnis im zugehörigen LibreDesk-Ticket dokumentieren.
