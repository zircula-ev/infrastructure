# IT-Admin Knowledge Base

Willkommen in der internen Wissenssammlung für die tägliche IT-Administration
von WERK × ZIRCULA.

Hier geht es um die sichere Nutzung der Oberflächen. Technische Änderungen an
Server, Docker, Datenbanken oder Konfigurationsdateien stehen bewusst nicht
hier, sondern in der Infrastruktur-Dokumentation.

## Die vier Arbeitsbereiche

- **Authentik:** Konten, Gruppen, Einladungen und MFA
- **Grafana:** Messwerte, Dashboards und technische Alarme
- **Uptime Kuma:** Erreichbarkeit der öffentlichen Dienste
- **LibreDesk:** Supportanfragen gemeinsam bearbeiten

## Grundregeln

1. Für administrative Arbeit immer das persönliche Konto verwenden.
2. Nur Änderungen durchführen, deren Wirkung klar ist.
3. Keine Passwörter, Tokens, Recovery-Links oder andere Secrets in Tickets,
   Chats oder Dokumentationen kopieren.
4. Kritische Änderungen und vorübergehend erweiterte Rechte nachvollziehbar
   dokumentieren.
5. Bei Unsicherheit zuerst in LibreDesk intern nachfragen oder an die
   verantwortliche Person eskalieren.

## Nicht Bestandteil dieser Knowledge Base

Ohne ausdrücklich abgestimmte Änderung werden insbesondere keine Authentik
Flows, Stages, Provider, Anwendungen, Brands oder Property Mappings verändert.
Ebenso werden keine provisionierten Grafana-Dashboards, Alarmregeln,
Benachrichtigungswege oder Serverkomponenten über die Oberfläche umgebaut.
