# Zuweisung, Tags und Abschluss

## Zuweisung

Jedes aktive Ticket soll eine erkennbare Zuständigkeit haben. Eine Zuweisung
bedeutet: Diese Person behält den Fall im Blick. Bei Urlaub oder Übergabe wird
sie angepasst.

## Tags

Tags machen Fälle auffindbar und unterstützen spätere Auswertungen. Verwende
bestehende Tags einheitlich. Neue Tags werden nur angelegt, wenn kein passender
Begriff existiert und der neue Tag auch künftig sinnvoll ist.

## Abschluss

Vor dem Schließen prüfen:

- Anfrage wurde beantwortet oder Lösung bestätigt
- notwendige Änderung ist nachvollziehbar dokumentiert
- keine offene Rückfrage wurde übersehen
- Zuweisung und Tags passen
- gegebenenfalls wurde auf weiterführende Anleitung verwiesen

Ein geschlossenes Ticket kann bei einer neuen Antwort wieder aktiv werden. Eine
Entwarnung eines Monitoring-Alarms ist nicht automatisch die Ursachenanalyse;
bei relevanten Störungen werden Dauer und vermutete oder bestätigte Ursache
ergänzt.
